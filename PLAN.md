# Spotify + YT Music Hybrid Player — Plan

## Concept
We are transforming `/Users/iandodge/Documents/Spotify-UI-Clone` from a static HTML/CSS/JS template into a full-featured, **Vercel-deployable** local + static music player web app that blends the best of Spotify (rich 3-pane layout, Daily Mixes, crossfade, smart playlists, library & album views) and YouTube Music (one-click "Start Mix" radio anywhere, dynamic mood/vibe tuning pills like *Familiar / Discover / Deep Cuts / Upbeat / Chill*, real-time "Up Next" queue drawer, and endless autoplay). It runs 100% statically out-of-the-box for 1-click Vercel deployment (via a pre-indexed `tracks.json` manifest + browser File System / Drag-and-Drop IndexedDB audio support), while also providing a dev script to auto-index any local `/songs` folder. When complete, it will be pushed to a new private GitHub repository (`main` branch) with a 1-click **"Deploy with Vercel"** button at the top of `README.md`.

### 4. Hybrid Recommendation & Scoring Engine (`recommender.js`)
- **Files created/updated**:
  - `recommender.js` (universal browser `window.SpotTubeRecommender` + CommonJS `module.exports` multi-signal recommendation and scoring engine)
  - `index.html` (loaded `<script src="recommender.js" defer></script>` after `storage.js` and before `script.js`)

- **How it works & Key APIs for later steps (`window.SpotTubeRecommender`)**:
  - **Core Weights (`DEFAULT_WEIGHTS`)**:
    - `artistAffinity: 0.22`, `genreEraCluster: 0.22`, `audioSimilarity: 0.28`, `tasteAffinity: 0.28`.
  - **Signal Functions**:
    - `buildCollaboratorGraph(catalog)` -> returns `Map<normalizedArtist, Set<normalizedCollaborator>>` across primary and featured artists.
    - `computeArtistCollaboratorAffinity(candidate, seedTracks, collaboratorGraph)` -> scores `1.0` (`"same-primary-artist"`), `0.86` (`"primary-featured-crossover"`), `0.76` (`"shared-featured-artist"`), or `0.56` (`"collaborator-network"` 1-hop graph neighbor).
    - `computeGenreAlbumEraCluster(candidate, seedTracks)` -> combines exact/token genre match (`0.36`), subgenre Jaccard overlap (`0.24`), language match (`0.18`), Gaussian era proximity (`0.14`, $\sigma = 7$ years), and album match (`0.08`).
    - `extractAudioFeatureVector(track, storage)` -> returns an 8D normalized vector `[energy, valence, danceability, acousticness, normalizedTempo, bassEnergy, trebleEnergy, spectralCentroidNormalized]`, merging static catalog features with live Web Audio API analyzer cache via `storage.getEffectiveAudioFeatures(track)`.
    - `computeTempoHarmony(bpmA, bpmB)` -> evaluates both direct BPM proximity and octave/half-time/double-time harmonic locking (e.g. 81 BPM vs 162 BPM).
    - `computeAudioFeatureSimilarity(candidate, seedTracks, storage)` -> combines 8D vector `cosineSimilarity` (`0.32`), perceptual L1 feature proximity (`0.34`), `tempoHarmony` (`0.16`), and mood tag overlap (`0.18`).
    - `computeUserTasteScore(candidate, { storage, catalog, now })` -> combines `storage.computeTasteAffinity(trackId, now)` with artist-level taste generalization (`artistTasteBoost` in `[-0.10, +0.14]` when the user has liked or completed other songs by the candidate's artist) and an unplayed popularity prior.
    - `computeVarietyAndRecencyPenalty(candidate, { storage, now, recentTrackIds, queueContext })` -> computes `recencyPenalty` (from `recentlyPlayed` position and exponential time decay `< 60 min`), `artistFatiguePenalty` (penalizing back-to-back same primary artist or repeated appearances in `queueContext`), and `albumClusterPenalty`.
    - `computeMixModeAdjustment(candidate, signals, { mixMode, moodFilter, storage })` -> dynamically shifts scores for YT Music tuning modes: `"all"`, `"familiar"`, `"discover"`, `"deep-cuts"`, `"upbeat"`, and `"chill"`.
  - **High-Level Ranking & Recommendation APIs (for Item 5 `queue.js`, Item 6 Mix Tuning, Item 8 Detail Views, Item 9 Search Mix, and Item 10 Smart Auto-Mixes)**:
    - `resolveSeedTracks(catalog, seedSpec)` -> accepts a track object, track ID, array of tracks, `{ artist }`, `{ album }`, `{ mood }`, or `{ query }` and resolves the matching seed tracks.
    - `scoreCandidate(candidate, context)` -> returns `{ trackId, track, totalScore, baseScore, mixMode, mixModeAdjustment, breakdown, reasons, primaryReason }`.
    - `rankCandidates(catalog, options)` -> greedy variety-aware sequential ranker that updates `rollingQueueContext` after each pick so consecutive recommendations avoid artist/album streaks.
    - `recommendTracks(catalog, options)` -> returns ordered track objects with `.recommendation` (`{ totalScore, breakdown, reasons, primaryReason, mixMode }`) attached.
    - `getSimilarTracks(catalog, referenceTrackOrId, options)` -> convenience helper for Item 8 ("Similar in Your Library").

  - `index.html` (loaded `<script src="queue.js" defer></script>` after `recommender.js` and before `script.js`; added `#clear-manual-queue-btn` and `#queue-live-status` `role="status"` live announcement region in `#panel-up-next`)
  - `style.css` (added styling for `.queue-drag-handle`, `.queue-item.manual-queue-item`, `.queue-source-pill`, `.queue-item-actions`, `.queue-action-btn`, `.card-quick-actions`, `.card-action-btn`, `.visually-hidden`, and reduced-motion view transition rules)

  - `tests/queue.test.js` (automated test suite verifying universal Start Mix across all 6 seed sources, Play Next, Add to Queue, manual reorder, moveUp/moveDown, promoteToPlayNext, removal, endless nonstop replenishment, playback history, and DOM shell integration)
- **How it works & Key APIs for later steps (`window.SpotTubeQueue` & `window.SpotTubeShell`)**:
  - **Queue Manager Factory & Default Singleton (`window.SpotTubeQueue`)**:
    - `createQueueManager({ catalog, storage, recommender, mixMode, moodFilter, autoplay, minQueueSize })` creates an isolated queue manager instance; all methods are also exposed directly on the default `window.SpotTubeQueue` singleton.
  - **Universal Radio Mix Generator (`startMix(seedSpec, options)`)**:
    - Normalizes any seed via `normalizeMixSeed(catalog, seedSpec, options)` and starts an endless radio session (`mixSession: { id, type, badge, label, autoplayLabel, seedTracks, artist, album, mood, searchQuery, startedAt }`):
      - Single Track (`{ type: "track", track | trackId }` or track object/ID) -> badge `"TRACK RADIO"`, label `"<Title> • <PrimaryArtist>"`
      - Artist (`{ type: "artist", artist }`) -> badge `"ARTIST RADIO"`, label `"<Artist> Radio"`
      - Album (`{ type: "album", album }`) -> badge `"ALBUM RADIO"`, label `"<Album> Radio"`
      - Mood Chip (`{ type: "mood", mood }`) -> badge `"MOOD MIX"`, label `"<Mood> Vibe Radio"`
      - Active Search Result Set (`{ type: "search", query, tracks }`) -> badge `"SEARCH MIX"`, label `'Search Mix: "<Query>"'`
      - Catalog Supermix (`{ type: "supermix" }` or `"supermix"`) -> badge `"SUPERMIX"`, label `"Your Nonstop Supermix"` (seeded by user's liked/high-affinity tracks)
    - Selects the highest-affinity lead track (`currentTrack`) unless `options.keepCurrentTrack: true` is passed, and populates the upcoming radio queue using `SpotTubeRecommender.recommendTracks`.
  - **Live Queue Operations**:
    - Each queue entry has shape `{ queueId, trackId, track, source: "manual" | "mix", manualType: "play-next" | "add-to-queue" | null, userReordered, addedAt, recommendation }` and attaches `track.queueMeta` on `getUpcomingTracks()`.
    - `playNext(trackOrId)` -> inserts at index `0` (`source: "manual"`, `manualType: "play-next"`), deduplicating any auto-mix copy of that track.
    - `addToQueue(trackOrId)` -> appends to the manual priority block (FIFO after existing `"manual"` items, ahead of auto-generated `"mix"` items).
    - `removeFromQueue(queueIdOrIndexOrTrackId)` -> removes the target entry and auto-replenishes if queue drops below `minQueueSize` (`3`).
    - `reorderQueue(fromIndex, toIndex)` / `moveUp(target)` / `moveDown(target)` / `promoteToPlayNext(target)` -> reorders queue items in place and flags `userReordered: true`.
    - `clearQueue({ onlyManual })` -> clears all upcoming items or only manually queued items.
    - `advanceNext({ shuffle, repeat })` / `previous()` / `jumpToQueueItem(target)` -> advances playback respecting manual queue priority first, records `history` stack for `previous()`, and calls `replenishQueue()` automatically when fewer than `minQueueSize` (`3`) tracks remain so radio playback is nonstop.
    - `setMixMode(mixMode)` -> re-ranks upcoming `"mix"` tracks for the selected YT Music mode while keeping `"manual"` items at the front without interrupting `currentTrack`.

- **How it works & Key APIs for later steps (`window.SpotTubePlayer` & `window.SpotTubeShell`)**:
  - **Dual-Deck Gapless & Crossfade Engine (`createPlayerEngine` / `window.SpotTubePlayer`)**:
    - Maintains two HTML5 Audio decks (`deckA` and `deckB`) routed through Web Audio API `GainNode`s (`gainNodeA`, `gainNodeB`) and a shared `AnalyserNode` when `AudioContext` is available, with automatic HTML5 `audio.volume` fallback.
    - `computeCrossfadeGains(progress)` -> equal-power cosine/sine curve (`outgoingGain = cos(p * π / 2)`, `incomingGain = sin(p * π / 2)`).
    - `setCrossfadeSeconds(seconds)` / `cycleCrossfadeSeconds()` / `getCrossfadeSeconds()` -> configurable `0–12s` crossfade (`CROSSFADE_PRESETS = [0, 2, 4, 6, 8, 12]`), persisted in `SpotTubeStorage.setPreferences({ crossfadeSeconds })`.
    - `preloadNextTrack(nextTrack)` -> gaplessly buffers the next queued track on the inactive standby deck (`standbyDeck`).
    - `evaluatePlaybackTick(currentTime, duration)` -> called on `timeupdate`; ensures endless queue replenishment whenever `queue.length < 3`, updates MediaSession position state, and automatically triggers `beginCrossfade(nextTrack)` when `remainingSeconds <= crossfadeSeconds`.
    - `beginCrossfade(nextTrack, options)` / `stepCrossfade(progress)` / `completeCrossfade()` -> smoothly crossfades from the outgoing deck to the incoming standby deck while recording natural completion telemetry (`endedNaturally: true`) on `SpotTubeStorage`.
  - **Keyboard Shortcuts (`handleKeyDown` / `SpotTubeShell.handleShellKeyDown`)**:
    - Automatically ignored when focus is inside `<input type="search|text">`, `<textarea>`, `<select>`, or `[contenteditable="true"]` (except `Escape` which closes `#shortcuts-modal` or blurs the input).
    - Shortcuts: `Space` / `K` (Play/Pause), `N` / `Shift+ArrowRight` (Next track), `P` / `Shift+ArrowLeft` (Previous track), `ArrowLeft` / `J` (Seek -5s), `ArrowRight` / `L` (Seek +5s), `ArrowUp` / `ArrowDown` (Volume +5% / -5%), `M` (Mute/Unmute), `Q` (Toggle Up Next Drawer), `S` (Shuffle), `R` (Repeat), `F` (Like current track), `X` (Cycle Crossfade 0–12s), `/` (Focus `#search-input`), `?` (Toggle `#shortcuts-modal`).
